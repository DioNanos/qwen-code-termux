# Test Suites

Runnable test checklists for Qwen Code Termux Edition.

## Index

- **Latest**: `latest/` — Current release (v0.10.3-termux)
- **Legacy**: `legacy/` — Historical versions

## Available Suites

| Suite                | File                | Purpose                        |
| -------------------- | ------------------- | ------------------------------ |
| QWEN Test Suite      | `qwen-test-suite.md`| Full validation suite          |
| Basic Smoke          | `basic-smoke.md`    | Quick core functionality check |
| Termux Runtime       | `termux-runtime.md` | Termux-specific tests          |

## Quick Start

1. Install: `npm install -g @mmmbuto/qwen-code-termux@latest`
2. Run: See `qwen-test-suite.md` or `latest/termux.md`
3. Report: Save in `test-reports/<version>/`
